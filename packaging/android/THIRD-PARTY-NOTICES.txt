raylib 1.10 Engine for Android: third-party notices
===================================================

No game data (IWAD or PWAD) is included: the player supplies their
own WAD files. The app is compatible with DOOM WAD files; it is not
made or endorsed by id Software, Bethesda or ZeniMax.

The program (libraylibdoom.so) links raylib 5.5 statically, with the
single-file libraries bundled in it, and the Android NDK's
native_app_glue. These are covered by the entries below. Where a
library offers a choice of licenses, the one used here is named
first. On Android raylib uses only system libraries (EGL, OpenGL ES,
AAudio through miniaudio); none of them is redistributed. The source
code of each release is at
https://github.com/raydelto/raylib_DOOM/tree/<tag>.
